# Problem Statement
In automated robotics and grid-based pathfinding systems, simulating robot movement, obstacle avoidance, and resource management (such as battery levels and step counts) in dynamic environments is crucial before physical deployment.   


## Scope of the Project
Development of an interactive Python-based command-line interface (CLI) simulation tool that allows users to define custom start coordinates, target destinations, and obstacle configurations, while tracking real-time metrics like battery consumption, traveled paths, and avoidance statistics.   


## Target Users
Robotics engineering students, hobbyists, and developers looking to test, visualize, and evaluate grid-based navigation algorithms and basic simulation workflows.   


## High-Level Features

- Interactive CLI menu system with robust input validation.   


- Dynamic obstacle placement with boundary and collision checking.   


 - Real-time robot status monitoring (position, battery percentage, steps taken, and obstacles avoided).   


- Complete path history logging and trajectory tracking.
